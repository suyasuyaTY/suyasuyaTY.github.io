記事のタイトルにあるように、個人サイトをNext.jsからAstroで構築しなおしました。

## 移行のモチベーション
もともと、今年の5月にNext.jsで個人サイトを作ったばかりでした。

ですが、雑な実装でよくわからないままライブラリを導入して魔実装した結果パフォーマンスが終わってしまったため、1から作り直したいと思っていました。

特にページを最初に開いた時のレンダリングがめちゃくちゃ遅かったり、ページ遷移をカーテンのような遷移をしたかったのにレンダリングが間に合っていなかったり...。

## Astroを採用した理由

前回サイトを作った際、「ブログを自分のサイト内で管理したい」という思いがありました。というのも、note では記事一覧を取得するための公式 API が存在せず、内容を手作業で入力する必要があり、その作業が負担だったからです。

こうした前回の反省と今回の目標を踏まえ、以下のメリットがある Astro を採用することにしました。

- 高パフォーマンス
- ページ内でインタラクティブにしたい部分では React を使用できる
- Markdown ベースのコンテンツ管理が、公式プラグインを使って簡単に実装できる
