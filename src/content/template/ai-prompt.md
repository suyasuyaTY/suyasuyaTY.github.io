# 記事を書くときに AI アプリへ渡す指示

ChatGPT や Claude のアプリで記事を書いたら、最後に次の指示を送って frontmatter の `summary` を作る。
`summary` がない記事は `npm run check` / `npm run build` が失敗し、main に merge できない。

---

この記事の要約を書いてください。記事のフロントマターの `summary` にそのまま貼ります。

- 150〜220字の日本語で、1段落にする
- 記事を読む前の人が「何について、どんな結論の記事か」を掴めるようにする
- 記事に書いてある事実だけを使い、書いていないことは足さない
- 「この記事では」などの前置きは付けず、常体（〜した、〜だ）で書く
- 改行・Markdown・引用符は使わない
- 出力は要約の本文だけにする
